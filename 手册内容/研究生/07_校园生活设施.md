# 校园生活设施

## 一、银行

一期食堂旁的综合楼二楼有工商银行ATM和中国银行ATM（存款提款一体机）。

## 二、超市

- 一期食堂旁边综合楼的鹭银海天猫校园超市：7:30-23:30 营业
- 二期食堂三楼的鹭银海超市：8:00-23:00 营业
- 中期食堂旁边综合楼一楼的鸿润福超市：7:30-23:30 营业

## 三、事务中心

- 学生会办公室：信息学院翔安校区1号楼106，周一到周日 20:00～22:00
- 社联评议中心：芙蓉9-10，周日到周五 20:00-22:00
- 翔安校区公寓办：
  - 翔安一期公寓办：学生事务大厅一楼
  - 翔安二期公寓办：笃行9～10之间
  - 周一到周日 08:00～11:30、14:30～17:30、18:30～22:00（寒暑假所有业务请至翔安一期公寓办办理）
- 学生事务大厅：学生活动中心，正常工作日
- 辅导员办公室：翔安校区西部片区1号楼102、103，正常工作日
- 辅导员联系电话：0592-2880193

## 四、医务室

一期学生公寓南安1号楼一层（从东大门进，右转直走）

值班电话：0592-2886120

## 五、心理咨询室

地址：学生活动中心二层

预约方式：在学工系统（https://xmuxg.xmu.edu.cn）中选择学生应用，找到心理咨询模块，点击预约。也可电话预约：0592-2886525。

## 六、药店

- 医务室就有药，可以刷医保
- 综合楼三楼（即一期食堂旁边那栋楼）有一家药房
- 东门外临街也有一家药店

## 七、文印店

- 一心一印（一期学生公寓综合楼一楼）
- 印佳德（二期学生公寓综合楼三楼）
- 图书馆二楼自助打印服务，这里可以照证件照
- 部分宿舍公寓一楼、部分教学楼一楼、学生活动中心的24h自动打印机，可在"宅印"微信小程序上面上传需要打印的文件、快速打印。且小程序中可以查看每台打印机的位置以及开放情况。

## 八、洗衣房

翔安校区洗衣房位置统计表：

| 园区 | 洗衣房位置 |
| --- | --- |
| 芙蓉园区 | 芙蓉1、3、10一楼 |
| 南安园区 | 南安6、12一楼 |
| 国光园区 | 国光3、6、8、10一楼 |
| 映雪园区 | 映雪2、4、6一楼 |
| 博学园区 | 博学1、4、7、10一楼 |
| 笃行园区 | 笃行8一楼 |
| 五期国光 | 每个宿舍都配备了一台洗衣机 |

洗衣房洗衣需自备洗衣液（粉），有的可刷卡支付，有的可按照洗衣机上提示扫码网络支付（微信支付），2-3元一次，洗衣时间为25-40min，请及时将衣物取回，以免丢失或影响他人使用。同时还有烘干机可以使用（需另外支付）。

## 九、打印、拍照片、洗照片

一期、二期综合楼的文印店可提供打印、证件照等服务；德旺图书馆三楼D区设摄影棚，预约请通过图书馆官方入口办理。
