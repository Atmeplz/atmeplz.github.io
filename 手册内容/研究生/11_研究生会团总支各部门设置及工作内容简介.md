# 研究生会、团总支各部门设置及工作内容简介

## 一、研究生会

### 1. 主席团

主席团全面负责主持研究生会的各项工作，确立研究生会的总体工作思路，全面贯彻学校与学院老师的指示精神，协调各个部门工作。

### 2. 办公室

办公室是研究生会的综合管理部门，负责研究生办公室的日常工作，如：

1. 研会财务开支的报销；
2. 各项活动的物资预算表制作、审核，以及物资的购买；
3. 研究生证的补办；
4. 研会内部各项活动资料的整理归纳，如网盘、表格等；
5. 研会各项通知的编辑和发布，如信息学院青年学生研究生骨干培训班通知等。

### 3. 就业指导中心

就业指导中心是负责研究生生涯发展与就业指导、服务和管理的职能部门。与社会各用人单位开展长期人才交流合作；邀请各用人单位来校招聘；收集和发布招聘信息，组织各类招聘活动；组织各类重点单位岗位体验和挂职锻炼项目等。

### 4. 权益部

权益部主要负责收集学生的权益问题并及时反馈；负责推免夏令营住宿安排、宿舍卫生检查相关各类事项；负责学院各项荣誉称号评定的审议工作。

### 5. 文体部

文体部主要职责是举办学院内部文体活动，以及负责对接院内球队，如：

1. 组织参与各项校级比赛，如校运会等；
2. 主办学院各项体育活动，如新生运动会、研究生篮球联赛等；
3. 各种文艺活动的主办，如毕业晚会等；
4. 学院各个球队的联络，如羽毛球队、乒乓球队、篮球队、足球队、排球队和棒球队等。

### 6. 学术科创部

学术科创部负责提供学术信息、组织和筹备研究生学术活动、奖学金评定等工作，旨在充分调动学院研究生的科研积极性。

## 二、研究生团总支

### 1. 书记处

团总支书记处熟悉掌握全院研究生团组织的基本情况，了解基层团组织的活动。与研究生会主席团相互配合，指导研究生会开展正常工作，结合学院特点，开展健康有益的活动，丰富学生的课余文化生活；了解掌握团员青年的思想动态，及时向学院反映青年团员的学习、文娱、生活等方面的意见和建议。

### 2. 青年发展部

青年发展部主要负责志愿者招募、志愿者工时审核录入工作、完善组织成员考核制度、做好成员考核工作，为组织的建设提供人才服务和保障。

### 3. 组织部

组织部负责根据学院党委和团委的各项要求，组织策划研究生会、团总支重大活动；参加院系研究生会、团总支大型活动的组织协调工作，并负责组织社会实践工作。

### 4. 宣传中心（采编部）

采编部通过拍摄活动现场，撰写新闻稿等方式，以精确的镜头捕捉与生动的文字记录，传递工作的信息，反映院内动态，向学院和学校宣传研究生会和团总支的活动与形象。

### 5. 宣传中心（新媒体中心）

新媒体中心通过制作海报，运营学院公众号等方式，以精美的设计和现代化媒体渠道，传递工作的信息，反映院内动态，向学院和学校展示研究生会和团总支的活动与形象。
