# 厦大信院新生答疑平台（重建版）

从原站 `https://a8mrt3dfd1c6.meoo.fun/` 逆向还原并修复 bug 后的可维护版本。
纯静态 HTML/CSS/JS，**零依赖、可离线运行**，双击 `index.html` 即可打开。

## 目录结构

```
├── index.html          页面骨架（只管结构，不含内容）
├── css/
│   └── style.css       全部样式（含响应式、动效）
├── js/
│   ├── data.js         ★ 网站全部内容数据（改内容只动这个文件）
│   └── app.js          渲染与交互逻辑（一般不用动）
├── pic/                首页轮播照片（5:4 比例）
│   ├── 01.jpg … 07.jpg
│   ├── make_manifest.py     清单生成脚本
│   ├── 更新照片清单.bat     ★ 照片增删后双击它重新生成清单
│   └── photos.js            生成的照片清单（勿手改）
└── _archive/           逆向过程的原始素材与提取脚本（留档备查，可删）
```

### 轮播照片如何更新

1. 把照片放进 `pic/`（建议命名 `01.jpg`、`02.jpg`… 数字编号，比例 5:4，
   不同分辨率会自动裁成统一大小）
2. 双击运行 `pic/更新照片清单.bat` 重新生成 `photos.js`
3. 刷新页面即可（浏览器可能短时缓存 photos.js，强刷一次最保险）

## 如何修改内容

所有文字内容都集中在 `js/data.js`：

| 字段 | 说明 |
|---|---|
| `siteName` / `platformName` | 站点名称（标题、页头、页脚） |
| `badge` / `heroSubtitle` | 首页大标题区的徽章和副标题 |
| `hotSearches` | 热门搜索标签 |
| `nav` | 顶部导航 |
| `faqTabs` | （已移除，问答分类由 `categories` 兼任） |
| `categories` | 六大板块卡片（点击弹出该板块问答弹窗，支持板块内搜索；`subCategories` 用于弹窗"涵盖"行与全站搜索索引） |
| `faqs` | 问答列表（`question`/`answer`/`views`/`isHot`；`category` 填板块卡片的 `id`） |
| `timeline` | 时间线节点（`type: "important"` 会高亮为重要） |
| `quickLinks` | 常用系统入口卡片 |
| `friendlyLinks` | 页脚友情链接 |
| `contact` / `copyright` | 页脚联系方式与版权 |

改完刷新页面即可生效。修改 `data.js` 后建议把 `index.html` 里
`?v=2` 的版本号 +1，避免访客浏览器缓存旧数据。

## 相比原站修复的问题

1. **搜索真正可用**：原站搜索只 `console.log`，现在会在搜索框下方
   就地展开结果面板（不跳转页面），逐条可展开查看，关键词高亮。
   搜索范围覆盖全站内容：问答、时间线、分类指南，结果带类型徽章；
   采用相关度评分排序（整词命中优先，其次按中文字符覆盖率），
   例如"军训安排"可命中时间线的"新生军训"。
2. **移除死按钮**：原站"查看完整详情"点击无任何反应，已移除。
3. **去掉虚标数字**：原站分类卡片上的问题数量（28/45/32…）与实际
   内容（共 10 条问答）完全不符，已删除。
4. **去掉平台水印**：右下角 meoo 推广水印已移除。
6. 新增：移动端汉堡菜单、滚动侦测导航高亮、键盘可操作（无障碍）、
   `prefers-reduced-motion` 支持。

## 本地预览

直接双击 `index.html`，或：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 部署

整个文件夹原样上传到任意静态托管（GitHub Pages、Gitee Pages、
对象存储、学校服务器）即可，无需构建。
